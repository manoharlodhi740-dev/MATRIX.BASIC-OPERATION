# 🚀 C++ Matrix & Array Operations Utility

A feature-rich C++ console application designed to perform various mathematical matrix computations ($3 \times 3$ matrices) as well as sorting and arrangement operations.

---

## ✨ Features

### 🧮 3x3 Matrix Operations
* **Add Column (`ADDCOLUMN`):** Calculates and displays the sum of individual columns in a $3 \times 3$ matrix.
* **Add Row (`ADDROW`):** Calculates and displays the sum of individual rows in a $3 \times 3$ matrix.
* **Diagonal Addition (`ADDDIAGONAL`):** Computes the sum of both diagonals:
  * **Left-to-Right (L-R):** Main/Principal diagonal sum.
  * **Right-to-Left (R-L):** Secondary diagonal sum.
* **Transpose (`TRANSPOSE`):** Swaps the rows and columns of a $3 \times 3$ matrix.
* **Whole Matrix Sum (`WHOLE MATRIX`):** Computes the total sum of all elements present in the matrix.
* **Add Two Matrices:** Performs element-wise addition of two separate $3 \times 3$ matrices.
* **Multiply Two Matrices:** Performs matrix multiplication (dot product) between two $3 \times 3$ matrices.

### 📊 1x1 / Array Operations
* **Ascending Order:** Arranges elements in ascending sequence.
* **Descending Order:** Arranges elements in descending sequence.
